# Get started

This kit is designed so you can stand up a credible data & AI governance
programme in weeks instead of months. You don't need to use everything — start
where the pressure is.

!!! tip "Not sure where you stand? Start with the assessment"
    The [role-based assessment](assess/index.md) asks only the questions relevant
    to your role, scores them by severity, and tells you which templates close
    your biggest gaps. It takes about ten minutes, and everything stays in your
    browser. If you would rather read first, carry on below.

## Three common starting points

=== "Brand-new programme"

    1. Baseline with the [Maturity Assessment](frameworks/maturity-assessment.md).
    2. Adopt the [Data Governance Framework](frameworks/data-governance-framework.md)
       and [AI Governance Framework](frameworks/ai-governance-framework.md).
    3. Stand up the [committee](operating-model/committee-charter.md) and agree
       the [RACI](operating-model/raci.md).
    4. Open the core [registers](registers/index.md).
    5. Take the first [board pack](board/board-pack.md) within a quarter.

=== "AI landing fast"

    1. Run the [EU AI Act Readiness Checklist](eu-ai-act/readiness-checklist.md).
    2. Populate the [AI System Inventory](registers/ai-system-inventory.md) and
       classify each system against the [timeline](eu-ai-act/timeline.md).
    3. Adopt the [Acceptable AI Use Policy](policies/acceptable-ai-use-policy.md)
       and [AI Development & Deployment Standard](policies/ai-development-standard.md).
    4. Assess your highest-risk systems with the
       [AI Risk Assessment](risk/ai-risk-assessment.md).

=== "Regulator or board is asking"

    1. Assemble a [board pack](board/board-pack.md) from what you have.
    2. Show the [risk register](registers/risk-register.md) and
       [control library](risk/control-library.md).
    3. Report progress against the
       [KPI / KRI dashboard](board/kpi-dashboard.md).

## How each template page is structured

Every template follows the same shape so the kit stays predictable:

- **Purpose** — what the artefact is for.
- **When to use it** — the trigger and cadence.
- **How to use it** — practical steps to adapt it.
- **The template** — the reusable content itself, ready to copy.
- **Adaptation notes** — sector, size, and jurisdiction tweaks.
