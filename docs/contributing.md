# Contributing

This kit is a commons. It gets better when practitioners who've done this work
contribute what they've learned. Corrections, new templates, sector variants,
and translations are all welcome.

## Ways to help

- **Flesh out a stub** — pages marked <span class="pill stub">Stub</span> or
  <span class="pill draft">Draft</span> need real content.
- **Correct or update** — regulation moves (the EU AI Act especially). If a date
  or obligation is stale, fix it and cite a source.
- **Add a variant** — a sector-specific version (financial services, health,
  public sector) or a size-specific one (startup vs enterprise).
- **Improve the site** — navigation, styling, accessibility.

## How to contribute

1. Fork the repo and create a branch.
2. Edit the relevant Markdown file under `docs/`.
3. Preview locally with `mkdocs serve`.
4. Open a pull request describing the change.

## House style

Keep every template page in the shared structure so the kit stays predictable:

**Purpose → When to use it → How to use it → The template → Adaptation notes.**

- Write in plain, practical English. Assume a busy practitioner.
- Use the status pill at the top of each page (`ready` / `draft` / `stub`).
- Cite sources for regulatory claims; prefer primary sources.
- Nothing here is legal advice — don't imply it is.
